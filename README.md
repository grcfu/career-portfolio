# Career Portfolio — Grace Fu

MGT Digital Career Portfolio. Static site, no build step.
Brand carried over from the technical portfolio at grcfu.github.io.

Live: https://grcfu.github.io/career-portfolio

## Local development

    python3 -m http.server 8000

Then open http://127.0.0.1:8000

## Filling it in

Every page carries dashed pink `.todo` blocks describing exactly what to
write there. Delete each block once that section is done — when no dashed
boxes remain, the site is finished.

Every content page ends with an AI Design Statement block. Each one needs
the tool named, what it helped brainstorm, and a working claude.ai share
link. Pieces written without AI should say so.
